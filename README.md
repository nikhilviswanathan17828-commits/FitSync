# FitSync - Gym Management System

## About the Project
FitSync is a Gym Management System developed using Python and Django. It helps gym administrators manage members, trainers, branches, membership plans, attendance, and payments efficiently.

## Technologies Used
- Python
- Django 6.0
- PostgreSQL
- HTML
- CSS
- Bootstrap
- JavaScript

## Features
- Admin Dashboard
- Member Management
- Trainer Management
- Branch Management
- Membership Plan Management
- Attendance Management
- Payment Management
- User Authentication
- PostgreSQL Database Integration

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd fitsync_core
```

3. Create a virtual environment:

```bash
python -m venv env
```

4. Activate the virtual environment:

```bash
env\Scripts\activate
```

5. Install dependencies:

```bash
pip install -r requirements.txt
```

6. Configure your PostgreSQL database and environment variables.

7. Run migrations:

```bash
python manage.py migrate
```

8. Start the development server:

```bash
python manage.py runserver
```
